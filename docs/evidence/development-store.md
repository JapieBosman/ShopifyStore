Confirmed by owner on 2026-09-28: `displaydeck.myshopify.com` is the Basic development store for the synthetic demonstration. It is not a merchant pilot or a production store.

The workspace has Shopify CLI 4.8.2 pinned locally. CLI sign-in succeeded and a development app named **Genesis Trade Suite** is linked to the Shopify React Router scaffold at `apps/shopify/genesis-trade-suite`. Shopify rejected the name containing “Shopify,” so the app's display name differs from the working product name. On 2026-09-28, `shopify app dev` reported the app installed on DisplayDeck and the embedded preview ready. The app requested no data scopes for this first connection test. The development URL is ephemeral and requires the CLI process to keep running. The separate Next admin remains a local-only preview, not the installed app.

The embedded home authenticates through Shopify's official React Router library and displays a fictional account credit decision calculated by `packages/domain/src/credit.ts`. This proves the app shell and domain integration, not order creation, ledger posting, Shopify payment sync or POS behavior. Restart the preview from the workspace root with `pnpm shopify:dev`; sign in to Shopify CLI again if its session expired. Keep CLI credentials and API secrets outside tracked files. Review every future scope against the API capability plan before adding it. Do not claim POS behavior until exercised in Shopify POS on the dev store.

The extension builds against API 2026-07 and the CLI dev preview includes it. A physical Shopify POS device has not yet displayed it, so its device behavior remains unverified. The modal cannot approve sales or access debtor balances.
